# UI-бриф визитки: контракт для всех секций

Дополняет план `2026-09-03-vizitka-astro-directus.md` (этапы 3–5) и спеку §2.
`docs/DESIGN.md` — источник правды по цвету, шрифту, радиусам, кнопкам и
паттерну «круг → пунктир → пилюля». Этот файл говорит, как из этих деталей
собрать каждую секцию, и что считать готовым.

## Общее

- **Регистр:** brand, консумерский, еда. Голос: домашний, прямой, тёплый.
  Фото главнее слов; текст — подпись к фото.
- **Токены:** только из `src/styles/global.css` (`--bg`, `--surface`, `--olive`,
  `--terracotta`, `--text-*`, `--line-*`, `--r-*`, `--gap`, `--sec-pad`,
  `--fs-*`). Новых цветов не вводить. Чёрного и белого нет.
- **Шрифт:** Montserrat Variable. H2 `--fs-h2` 800/1.07/−0.02em,
  `text-wrap: balance`; тело `--fs-body`, лид `--fs-lead`, `text-wrap: pretty`.
- **Кнопки:** `.btn` из global.css. Одна тёмная (`.btn--primary`) на секцию —
  главное действие; остальные `.btn--secondary` (обводка). На оливковом фоне
  `.btn--light`. Высоты: 46 основная, 42 в карточках, 48 на первом экране
  (мобильный). Добавить в `.btn`: `:active { scale: 0.96 }` с
  `transition: scale 120ms ease-out` и `@media (hover: hover) and (pointer: fine)`
  для hover-состояний.
- **Иконки:** инлайн-SVG 20/24 px, `stroke: currentColor`, `stroke-width: 1.75`,
  один набор на весь сайт (`src/assets/icons/*.svg` через `?raw` или общий
  `Icon.astro`). Существующие `tg.svg`, `max.png` остаются в `MessengerButtons`.
  Эмодзи запрещены. Иконка только с текстом или с `aria-label`.
- **Кикер `.kicker`** — элемент системы, но не грамматика: ставить только там,
  где он несёт информацию (месяц у афиши, адрес у ленты галереи). Не над каждым
  H2.
- **Карточки:** фон `--surface` или `--bg` с рамкой `1px solid var(--line)`,
  радиус `--r-xl`; внутренние радиусы концентричны (внешний = внутренний +
  паддинг). Теней нет. Полос-акцентов слева нет. Вложенных карточек нет.
- **Фото:** через `Photo.astro`/`<Image>`, `outline: 1px solid rgb(0 0 0 / .08)`
  поверх, плейсхолдер `--surface-photo`. Подпись на фото — поверх градиента
  снизу (`linear-gradient(to top, rgb(44 41 39 / .78), transparent 60%)`),
  текст `--bg`.
- **Motion:** цвет/рамка 160 мс `ease`; вход диалога и полосы 200 мс
  `cubic-bezier(0.23, 1, 0.32, 1)`, выход 150 мс; рельсы — `scroll-snap` +
  `scroll-behavior: smooth` только при `prefers-reduced-motion: no-preference`.
  Никаких въездов при скролле, `transition: all`, `ease-in`, `scale(0)`,
  анимации `height/width/top/left`. `prefers-reduced-motion` оставляет
  прозрачность, убирает движение.
- **Доступность:** контраст ≥ 4,5:1 (проверять текст на фото и на оливковом),
  `focus-visible` из global.css не перебивать, `aria-label` у icon-only кнопок,
  hit-area ≥ 44 px на тач, `<time datetime>` у дат, единственный `h1`.
- **Ширины:** 320 — без горизонтального скролла; 390 / 834 / 1440 — контрольные.
- **Копия кнопок (фиксировано):** «Забронировать стол», «Заказать доставку»,
  «Позвонить», «Приложение», «Меню», «В приложении», «На сайт», «Обсудить
  банкет», «Подробнее», «Смотреть меню», «Заказать в приложении», «Торт на
  заказ», «Торты в наличии», «Открыть магазин», «Маршрут», «Показать на карте»,
  «Открыть в Яндекс Картах», «Все отзывы», «Показать ещё», «Закрыть». Без стрелок
  «→» в тексте кнопок; без тире в копии.

## Диалог брони (`BookingDialog.astro`)

- Один `<dialog id="book">` в `BaseLayout`. Триггер — любой элемент с
  `data-book="Заголовок"`; необязательный `data-book-note="строка под
  заголовком"` (по умолчанию `home.contacts_note`).
- Содержимое: заголовок H2-размера, строка-подсказка, три действия столбиком:
  Telegram и Max через `MessengerButtons variant="dark" size="lg"`, «Позвонить
  +7 987 955-25-65» `.btn--secondary` с `tel:`. Кнопка закрытия — круглая
  40 px в правом верхнем углу, крестик SVG, `aria-label="Закрыть"`.
- Мобильный: лист снизу, `inset-block-end: 0`, радиус 24 сверху, ручка не
  нужна. Десктоп: по центру, ширина 420, радиус `--r-2xl`. `::backdrop`
  `rgb(44 41 39 / .45)`.
- Вход: `@starting-style` opacity 0 + `translateY(12px)` (десктоп) /
  `translateY(100%)` (мобильный) → 200 мс `--ease-out`; выход 150 мс через
  `transition-behavior: allow-discrete`. Reduced motion: только opacity.
- Escape и клик по фону закрывают; фокус возвращается на триггер (нативно).

## Шапка (`Header.astro`) и полоса (`StickyBar.astro`)

- Липкая, фон `--bg`, низ `1px solid var(--line-3)`; высота `--header-h`.
  Логотип слева, навигация по центру/слева, справа: телефон (табличные цифры,
  600), «Забронировать стол» (`.btn--secondary btn--sm`), «Заказать доставку»
  (`.btn--primary btn--sm`).
- Навигация из `navFor(content)`: Главная · Афиша (если есть) · Доставка ·
  О нас · Меню · Контакты. Один фрагмент разметки для десктопа и мобильного
  меню (не дублировать список).
- Мобильный (< 768): логотип, кнопка-телефон (иконка + `aria-label`), бургер.
  Меню раскрывается панелью под шапкой, внизу панели обе CTA `btn--block`.
  При открытом меню `body { overflow: hidden }`.
- `StickyBar`: только < 768, `position: fixed; bottom: 0`, две кнопки в ряд:
  «Позвонить» (`.btn--secondary`) и «Заказать доставку» (`.btn--primary`),
  фон `--bg`, верхняя рамка, `padding-bottom: env(safe-area-inset-bottom)`.
  Скрыта (`translateY(100%)`), появляется после выхода `#hero` из вьюпорта
  (IntersectionObserver), 200 мс. `body` получает `padding-bottom` под полосу.

## Первый экран (`Hero.astro`, `#top`)

- Фото `home.hero_image` на весь экран: мобильный `min-height: 100svh`, с 768
  `min-height: 82vh`, `object-fit: cover`, `object-position: center 40%`.
  LCP: `eager`, `fetchpriority="high"`, `sizes` из одной константы
  `HERO_SIZES` в `src/lib/hero.ts`, preload в `BaseLayout` из неё же.
- Поверх — скрим `linear-gradient(to top, rgb(44 41 39 / .86) 0%, rgb(44 41 39
  / .55) 45%, transparent 78%)`. Текст `--bg` и `--surface`.
- Контент прижат к низу слева, `max-width: 640px` на десктопе: пилюля афиши
  (если `content.afisha`: «Афиша · 26 сентября · Вечер живой музыки», ссылка на
  `#afisha`, светлая полупрозрачная подложка `rgb(255 250 237 / .16)` с рамкой
  `rgb(255 250 237 / .35)`), единственный `h1` = `home.hero_title`, лид =
  `home.hero_text`, две кнопки (48 px): «Заказать доставку» `.btn--light`
  (светлая заливка на тёмном), «Забронировать стол» `.btn--ghost-light`
  (`data-book`). Ниже строка: телефон крупно (табличные цифры) и две пилюли
  адресов «Садовая, 212Б · до 21:00» (`OpenStatus`, ссылка на `#contacts`).
- Дубля H1 нет. Мобильный: кнопки `btn--block` столбиком, пилюли адресов в
  строку с переносом.

## Направления (`Directions.astro`, `#about`)

- `section-head`: H2 `home.about_title`, лид `home.about_text`.
- Сетка: 768+ — две большие карточки в ряд, ниже три малые в ряд; 1200 —
  то же, ширины 1fr 1fr / 1fr 1fr 1fr; < 768 — колонка.
- Большая карточка (`cafe`, `restaurant`): фото 16:9 сверху (`--r-lg` внутри
  карточки `--r-xl` с паддингом 4 px концентрично), тело: `.card-top` (круг
  с номером точки `place.n` → пунктир → `OpenStatus` пилюля), H3 `title`,
  текст, строка «Сегодня 8:00 — 21:00 · Садовая, 212Б» (табличные цифры),
  кнопки: «Забронировать» `.btn--primary btn--md`
  (`data-book="Бронь стола: {place.street}"`), «Приложение»
  `.btn--secondary btn--md` → `#delivery`, телефон текстовой ссылкой.
- Малая карточка (`confectionery`, `catering`, `banquets`): `.card-top` (круг
  с иконкой 20 px: торт / клош / бокалы → пунктир → пилюля с коротким словом:
  «48 часов» / «выезд» / «от 10 гостей»), H3, текст, кнопки по таблице в
  компоненте:
  - confectionery: «Меню» → `menuFor(confectionery).file.href` (если есть),
    «В приложении» → `settings.shop_url`, «Позвонить» текстом;
  - catering: «На сайт» → `settings.catering_url` (`target=_blank`),
    «Позвонить»;
  - banquets: «Обсудить банкет» (`data-book="Банкет"`,
    `data-book-note="Скажите дату, число гостей и повод"`).
- Кнопки внутри малых карточек `.btn--secondary btn--md`; тёмная только у
  больших.

## Афиша (`Afisha.astro`, `#afisha`)

- Рендер только при `content.afisha`. Сетка 768+: `5fr 7fr`, постер слева
  (`<Image>` в натуральной пропорции, `max-width: 480px`, `--r-xl`, outline),
  справа выравнивание по центру по вертикали: `.kicker` «Афиша · сентябрь»,
  H2 `title`, строка `<time>26 сентября</time>, 19:00 · Советской Армии, 177`,
  текст, кнопки: «Забронировать стол» `.btn--primary` (`data-book="Бронь стола:
  {place.street}"`), «Подробнее» `.btn--secondary` при `link`.
- < 768: постер на всю ширину колонки, затем текст и кнопки `btn--block`.
- Даты через `Intl.DateTimeFormat('ru-RU', { day: 'numeric', month: 'long' })`.

## Акции (`Promos.astro`, `#promos`)

- Рендер только при `livePromos().length`. H2 «Акции», без лида.
- Группы `groupByPlace`: сначала «Обе точки» (`null`), затем по `places`.
  Внутри секции одна сетка `repeat(auto-fit, minmax(280px, 1fr))`, группы не
  разделяются заголовками: адрес подписан внизу каждой карточки.
- Карточка: H3 `title`, текст, кнопка по `cta` (`book` → «Забронировать стол»
  `data-book`, `order` → «Заказать доставку» → `settings.shop_url`, `none` →
  нет), внизу строка `card-top`-стиля: короткий пунктир → подпись адреса
  `place?.name ?? 'Обе точки'` в `--text-4`. Кнопка прижата к низу
  (`margin-top: auto`), карточки одной высоты.
- Первая акция без адреса — на оливковой заливке (`.promo--hi`: фон `--olive`,
  текст `--bg`, кнопка `.btn--light`), остальные на `--surface`.

## Меню (`Menus.astro`, `#menu`)

- `section-head`: H2 «Меню», лид `home.menu_text`, справа действие секции
  «Заказать в приложении» `.btn--primary btn--sm` → `settings.shop_url`.
- Три карточки в ряд (768+), колонка на мобильном: `.card-top` (круг с
  иконкой направления → пунктир → пилюля «обновлено 1 сентября» из
  `menu.updated` или «скоро»), H3 = заголовок направления, строка `kind`
  точки или «пирожные, торты, конфеты», кнопка «Смотреть меню»
  `.btn--secondary btn--md` (`href=file.href`, `target=_blank`,
  `rel=noopener`), при отсутствии меню — текст «Меню скоро появится» без
  кнопки.

## Торты (`Cakes.astro`, `#cakes`)

- `section-head`: H2 `home.cakes_title`, лид `home.cakes_text`, действия:
  «Торт на заказ» `.btn--primary btn--sm` (`data-book="Торт на заказ"`,
  `data-book-note="Пришлите картинку, посчитаем в тот же день"`), «Торты в
  наличии» `.btn--secondary btn--sm` → `settings.shop_cakes_ready ??
  settings.shop_url`.
- Сетка 2 / 3 / 4 колонки, фото 3:4, подпись на фото: `title` 600 и `note`
  в `--surface` мельче. Видимы первые 8 (`nth-child(n+9) { display: none }`),
  кнопка «Показать ещё» (`.btn--secondary btn--md`, `aria-expanded`) ставит
  `.is-open` на сетку; кнопки нет, если тортов ≤ 8. Фильтров нет. Цен нет.

## Галерея (`Gallery.astro`, `#gallery`)

- Рендер только если у какой-то точки есть фото. H2 «Зал».
- На каждую точку с фото — блок: строка с H3 `place.name` слева и парой
  стрелок справа (круглые 40 px, `.btn--secondary`-обводка, SVG шевроны,
  `aria-label="Предыдущие фото"/"Следующие фото"`, `data-rail-prev/next`);
  под ней `.rail` (`data-rail`) с кадрами 4:3: ширина 82vw / 46vw / 31vw,
  `scroll-snap-align: start`, подпись `caption` под фото в `--text-4`, если
  есть. Стрелки скрыты при `@media (hover: none)`.
- `rail.ts`: `scrollBy({ left: ±cardWidth, behavior })`, `behavior` —
  `'smooth'` только без reduced-motion.

## Доставка и приложение (`Delivery.astro`, `#delivery`)

- Панель `--olive`, радиус `--r-2xl`, `.blob` в углу как у карточки приложений
  старого `Ecosystem.astro`. Текст `--bg`, вторичный `--surface`.
- 768+: две колонки `7fr 5fr`. Слева: H2 `home.delivery_title`, текст
  `home.delivery_text`, строка выгоды `home.delivery_note` крупнее (лид, 600),
  ряд кнопок: App Store и Google Play `.btn--light btn--md` с инлайн-SVG
  логотипами 18 px (`src/assets/icons/appstore.svg`, `googleplay.svg`,
  монохром `currentColor`), «Открыть магазин» `.btn--secondary btn--md`
  светлая обводка (`.btn--ghost-light`). Справа: мокап телефона — `div`
  260×540, фон `#2C2927`, радиус 40, паддинг 8, внутри `<Image>`
  `home.app_screenshot` с радиусом 32 (`object-fit: cover`), поворот
  `rotate(-6deg)` и сдвиг вниз на 24 px, чтобы срезаться панелью снизу
  (`overflow: hidden` у панели). Без скриншота колонка мокапа не рендерится, а
  сетка становится одной колонкой.
- < 768: мокап 200×415 по центру под кнопками, без поворота.

## Контакты (`Contacts.astro`, `YandexMap.astro`, `#contacts`)

- Структура как сейчас: две карточки точек (`.card-top` номер → пунктир →
  `OpenStatus`), часы `hoursRows`, кнопки «Маршрут» `.btn--primary btn--md`,
  «Показать на карте» `.btn--secondary btn--md`, ссылка «Открыть в Яндекс
  Картах» у каждой точки на свой `yandex_org`; карта справа; «Написать нам» с
  `home.contacts_note` и `MessengerButtons`.
- Карта: при `PUBLIC_YANDEX_MAPS_KEY` — JS API 3.0, две метки (круг 28 px
  `--terracotta` с белой цифрой, подпись адреса на светлой подложке), границы
  по обеим точкам с `margin: [40,40,40,40]`; «Показать на карте» → `setLocation`
  на точку + подсветка метки; без ключа — iframe-виджет с починкой из 5.2.
  Клик по метке → карточка организации.

## Готовность секции

1. `pnpm test && pnpm check && pnpm build` зелёные (с Directus и с фикстурой).
2. Скриншоты 390 и 1440 всей секции сняты и просмотрены исполнителем, потом
   мной; на 320 нет горизонтального скролла.
3. Каждое состояние прокликано: hover, focus-visible (Tab), active, пустые
   данные (нет афиши / акций / меню / скриншота), длинный заголовок.
4. Нет `transition: all`, `ease-in`, `scale(0)`, эмодзи, `#000/#fff`, теней,
   левых полос, вложенных карточек, дублей H1.
5. Консоль без ошибок в dev и в preview.
