# Хендофф: лендинг «Вкусная компания» (кондитерская, Самара)

## Что это
Одностраничный лендинг кондитерской с двумя точками: витрина, торты на заказ,
зал, отзывы, контакты. Основная конверсия — написать в **Telegram** или **Max**,
позвонить, либо перейти в отдельный магазин доставки.

## О файлах в этом пакете
Файлы здесь — **дизайн-референс, собранный в HTML**. Это прототип, показывающий
внешний вид и поведение, а **не продакшн-код для копирования**. Задача —
воспроизвести эти макеты в целевом стеке (React/Next, Vue, Nuxt — что уже есть в
проекте), по его собственным паттернам и библиотекам. Если стека ещё нет —
выбрать подходящий и реализовать там.

`Landing.dc.html` — единый компонент со всей вёрсткой. Все стили — инлайновые
объекты в `renderVals()` внутри `<script type="text/x-dc">` в конце файла;
разметка — в `<x-dc>` в начале. Значения (цвета, размеры, отступы) брать оттуда,
это источник истины.

## Фиделити
**Hi-fi.** Цвета, типографика, отступы, радиусы и состояния финальные.
Верстать пиксель-в-пиксель по трём брейкпоинтам.

Исключения — намеренные заглушки, контент ждём от клиента:
- Блок «О нас» — серые полосы вместо текста (`stub100/85/70`, `stubChip`).
- Контакты — адреса/телефоны как `Lorem ipsum, 00` и `+7 (000) 000-00-00`.
- Юридическая строка в футере — полоса-заглушка.
- Все фотографии — Unsplash-плейсхолдеры (см. «Ассеты»).

## Брейкпоинты
Объект `M` в коде. Значения — не «примерно», а ровно так:

| | mobile | tablet | desktop |
|---|---|---|---|
| дизайн-ширина | 390 | 834 | 1440 |
| боковой паддинг (`pad`) | 18 | 36 | 72 |
| H1 / H2 / H3 | 34 / 25 / 17 | 47 / 33 / 19 | 66 / 42 / 21 |
| body / lead | 14 / 15 | 15 / 17 | 16 / 19 |
| gap сетки | 12 | 16 | 20 |
| вертикальный паддинг секции (`secPad`) | 44 | 64 | 92 |
| колонок: торты / десерты / три-в-ряд / плитка | 2 / 2 / 1 / 3 | 3 / 3 / 3 / 3 | 4 / 3 / 3 / 4 |

## Секции по порядку
Нумерация в макете видна как тёмные пилюли-аннотации (`annTag`) — это
служебные метки для ревью, **в прод не переносить** (флаг `annotations`).

1. **Хедер** — sticky, `rgba(255,250,237,.94)` + `backdrop-filter: blur(8px)`,
   низ `1px solid #EFE6D6`. Слева логотип (132×42, на мобиле 104×42), по центру
   nav (Торты / Десерты / Зал / Контакты — только tablet+), справа: на desktop
   кнопка «Заказать доставку», на мобиле телефон + бургер `≡`.
2. **Первый экран** — три варианта (`heroVariant`), в проде **collage**:
   на desktop сетка `.85fr 1.15fr` — высокое фото слева на две строки, широкое
   16:9 справа сверху, текстовая карточка `#F6EEE3` r22 справа снизу.
   На мобиле — только высокое фото 3:4 с тёмным градиентом-скримом снизу,
   поверх — kicker, H1 31px, лид и две кнопки в столбик (высота 48).
   H1: «Печём с утра, пока не разберут».
3. **Бенто под первым экраном** — сетка 6 колонок (мобила: 2).
   Карточка часов `span 2` на оливковом `#868C56`, текст `#FFFAED`
   («Сегодня открыто» / 8:00 — 21:00 / уточнение); две светлые ячейки
   `#F6EEE3` + `1px #E9DECC` («48 ч на торт под заказ», «2 точки»);
   карточка «Написать нам» `span 2` на `#FBECE0` + `1px #F4D6BD`
   с двумя кнопками Telegram / Max.
4. **Торты** — заголовок + лид + кнопка «Свой торт по картинке».
   Сетка карточек 4/3/2 колонки, фото 3:4 (`mediaRatio` умеет 1:1), r16.
   Подпись — под фото (`captionInside: false`) или на фото поверх градиента.
   Сетка обрезана по высоте ~2.5 ряда с масочным фейдом снизу; кнопка
   «Показать ещё» раскрывает всё (`state.more`), рядом — «В витрине 12 тортов».
   Данные — массив `CAKES` (12 позиций: название, вес, срок, «от N ₽»).
5. **Панель «Торт по вашей картинке»** — `#F1EFE0`, r32 (мобила 26),
   декоративный круг `rgba(198,113,57,.10)` справа сверху.
   Слева: kicker, H3, лид, три тёмных пилюли (48 часов / от 3 500 ₽ /
   Предоплата 50%), четыре шага с тёмными кружками 38px и пунктирной
   вертикальной линией между ними, две кнопки (тёмная Telegram + ghost Max).
   Справа: два фото 4:5 «Ваша картинка» / «Наш торт», второе со сдвигом вниз.
6. **Пирожные, конфеты, наборы** — сетка 3/3/2, фото 1:1, подпись под фото.
   Данные — `SWEETS` (6 позиций).
7. **Зал** — широкое фото 16:7 (мобила 4:3) + три фото 4:3 в ряд. `DETAILS`.
8. **Как заказать** — три карточки. Шапка каждой: круг с номером 46px
   (`#2C2927`), пунктир `2px dashed #E4DBC9`, пилюля-статус справа
   («20–40 минут», «Сегодня», «48 часов»). Третья карточка — акцентная,
   на оливковом `#868C56`, с тем же паттерном в светлых тонах и двумя
   светлыми кнопками Telegram / Max. Кнопки прибиты к низу (`margin-top:auto`).
9. **Отзывы** — слева колонка с тёмной карточкой рейтинга (`#2C2927`):
   тот же паттерн шапки (кружок со звездой → пунктир → пилюля «За последний
   год»), крупная оценка 4,9 (58px), пять звёзд, подпись про 498 отзывов,
   две светлые кнопки-источника (Яндекс 4,9 / 2ГИС 4,8).
   Справа — карточки отзывов (`REVIEWS`, 5 шт): шапка «аватар-буква → пунктир →
   пилюля источника», цитата, имя + дата. Desktop — 2 колонки в шахматку
   (чётные со сдвигом 26px), мобила — горизонтальный скролл-рельс,
   карточка 80% ширины, snap, подпись «Свайп в сторону — ещё отзывы».
10. **О нас** — текст-заглушки слева, справа сетка 2×2: первое фото 16:10
    на две колонки, два остальных 1:1. `ABOUT`.
11. **Контакты** — шапка: kicker «Две точки в городе», H2, справа
    «Один номер на обе точки» + телефон крупным заголовочным шрифтом.
    Слева две карточки точек: шапка «номер 36px → пунктир → зелёная пилюля
    „Открыто“» (`#EDF0E0` / `1px #DCE2C6` / `#5F6439`), адрес, примечание,
    строка «Часы» через верхнюю линейку, тёмная кнопка «Позвонить +7 …».
    Справа — реальная карта OpenStreetMap (`osm-map.js`, Leaflet-free,
    центр 53.1959 / 50.1008, zoom 12, два тёмных пина с цифрами 1 и 2)
    в контейнере 4:3 r24, под ней оливковая карточка «Написать нам»
    с двумя светлыми кнопками.
12. **Футер** — `#F6EEE3`, слева «Вкусная компания» + строка-заглушка,
    справа ссылки (Магазин доставки, Кейтеринг, Приложение, Политика, Оферта)
    с подчёркиванием `1px solid #D6CBB8`.

## Повторяющийся паттерн (важно)
Единый визуальный язык всех карточек — **шапка из трёх элементов**:
круг (номер / буква / иконка) → растянутый пунктир → пилюля-статус справа.
Реализован как `howTop` + `howNum`/`ctNum`/`revAvatar`/`skNum` +
`howDash` + `howTime`/`statusStyle`/`srcStyle`. Держать его во всех новых
блоках — на нём стоит вся страница.

## Интерактив
- **Лайтбокс**: клик по кнопке `⤢` в углу фото (28px, `rgba(44,41,39,.5)`)
  открывает оверлей `rgba(24,21,18,.93)`, фото `contain` в боксе
  `min(88%,720px)` / 4:3. Закрытие — клик по фону или `×` справа сверху.
  В прототипе кнопки видны по флагу; в проде разумнее делать кликабельным всё фото.
- **Показать ещё** в тортах — разжимает обрезанную сетку.
- **Горизонтальные рельсы** (отзывы, фильтры, сторис): `overflow-x:auto`,
  `scroll-snap-type: x mandatory`, скроллбар скрыт, по краям масочный фейд,
  паддинги вытянуты за контейнер на `pad` чтобы карточки уходили под край.
- Состояния наведения/нажатия и фокус — из дизайн-системы (`styles.css`,
  `.btn`, `:focus-visible` — 2px аккцентный outline). Не заменять браузерными.
- Скрытые в проде флаги-варианты: сторис-кружки, фильтры-чипсы, цены на
  карточках, «Закончился», варианты Б/В сетки тортов, два альтернативных
  первых экрана (split / bleed). Всё это есть в файле — если понадобится,
  включается пропсами.

## Ассеты
- `assets/logo.png` — логотип (в макете подставлен в слот 132×42).
- `icons/tg.svg`, `icons/max.png` (+ png/svg дубли) — иконки мессенджеров, 18×18.
- Все фотографии — **плейсхолдеры Unsplash** (`pic()` в коде: id, автор, ссылка).
  Реальные фото ждём от клиента: минимум 8 тортов, 6 десертов, 4 по залу,
  2–3 с производства, 2 для блока «свой торт». Атрибуция Unsplash в прод не нужна —
  фото будут заменены.
- `screenshots/` — рендеры 390 / 834 / 1440.
- `_ds/organic-…/styles.css` — токены и компоненты дизайн-системы Organic
  (классы `.btn`, `.tag`, `.card`, `.input`, `.nav`). Кнопки в макете —
  её `.btn .btn-primary` / `.btn-secondary` с локальными размерами.

## Файлы
- `Landing.dc.html` — весь лендинг (разметка + стили + данные).
- `osm-map.js` — веб-компонент карты (OSM-тайлы, без зависимостей, свои пины).
- `image-slot.js` — плейсхолдер-слот под фото (drag-and-drop в редакторе).
- `support.js` — рантайм прототипа. В проде не нужен.
- `_ds/` — дизайн-система. `icons/`, `assets/` — ассеты. `screenshots/` — рендеры.

Чтобы посмотреть: открыть `Landing.dc.html` в браузере (нужен локальный сервер —
файл подтягивает соседние скрипты).
